
Bootstrap Event Registration Form

A simple, modern, and fully responsive event registration form template designed with Bootstrap 5.3.3. It features a clean card layout, centered alignment, and essential input fields styled for a smooth user experience.

✨ Features

• Responsive Design: Adapts seamlessly to mobile, tablet, and desktop screens using Bootstrap's grid system (col-md-*).
• Essential Fields: Includes inputs for First Name, Last Name, Email, Password, and Confirm Password.
• Dropdown Selection: Gender selection menu with disabled placeholder state.
• Validation & Terms: Built-in HTML5 required attributes and a mandatory Terms & Conditions agreement checkbox.
• Styling: Leverages Bootstrap utility classes for shadows (shadow-sm), background styling, and custom green header text.

🚀 Built With

• HTML5
• Bootstrap 5.3.3 (Loaded via official CDN with local fallback support)

📦 How to Use

1. Clone or download the repository to your local machine.
2. Ensure you have your bootstrap.min.css file in the project directory if working offline, or rely on the included CDN link.
3. Open index.html in any modern web browser to view and test the form.
